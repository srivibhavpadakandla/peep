# cipher
intelligent video surveillance

## Agentic Orchestration
This platform implements an intelligent agentic orchestration architecture consisting of a **monitoring agent**, a **reasoning agent**, and an **execution agent**. 

### Technical Implementation & Approach
The architecture leverages a hierarchical, event-driven pipeline where the monitoring agent continuously processes live video feeds using optimized computer vision models to detect anomalous events. Detected anomalies trigger structured alerts to the reasoning agent, which utilizes large language model (LLM) reasoning to evaluate context, assess potential threats, and formulate appropriate response strategies. Finally, the execution agent acts on these decisions by triggering automated protocols, capturing targeted footage, or notifying operators, ensuring a highly responsive and adaptive surveillance system.
